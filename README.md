# TBIPTV Player

TBIPTV Player is a media player for Xbox that plays IPTV playlists you already have (Xtream Codes logins and M3U playlists).

**It does not include, sell or link to any channels, films, series or subscriptions.** Users add playlists from services they are legally entitled to watch.

- [Privacy policy](PRIVACY.md)
- [Test playlist](test-playlist.m3u): public test streams and Creative Commons films only (Apple and Akamai HLS test streams; Big Buck Bunny and Tears of Steel by the Blender Foundation, CC BY 3.0). Used for Microsoft Store certification and screenshots.

Questions or problems: [open an issue](https://github.com/easalesltd/tbiptv-player/issues).
